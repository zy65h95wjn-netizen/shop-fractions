# TRT Calc

Standalone iPhone-friendly TRT medication math calculator published at `/shop-fractions/trt/`.

This app is isolated in the `trt/` directory. The shop fractions calculator remains at the repository root.

- All calculations run locally in the browser.
- Values are saved only in this device's local storage.
- After first successful load, the app's service worker can cache its own files for offline use.
- No treatment recommendations or pharmacokinetic predictions are made.
- Syringe marks assume U-100 syringe graduations; follow the medication label and prescribed dose.
